## Findings

1. **[blocker] `src/habits/core/services.py:28` and `src/habits/storage/repository.py:50` — A PATCH can undo another successful PATCH.** The service reads a habit, applies the patch to that snapshot, and passes the whole habit back to storage. If another request archives the habit between the two reads, a rename can write the old `archived=False` value back. A concurrent delete can also turn PATCH into an unhandled `LookupError`. Make the read, validation, and write atomic, or detect a stale write and reapply the original patch to the current row. Add two-session tests proving that a rename and an archive both survive, and that a delete winning the race produces `404 habit_not_found`.
2. **[blocker] `src/habits/storage/repository.py:62` — Concurrent deletes can both report 204.** Two sessions can each find the row before either deletes it. The method returns `True` even when its DELETE affects zero rows. Use a single DELETE and derive the result from its affected-row count. Test that two deletes of the same habit produce one 204 and one enveloped 404.
3. **[blocker] `src/habits/api/schemas.py:19` and `src/habits/api/schemas.py:35` — Body coercion accepts values the HTTP contract rejects.** A weekly habit can accept `target_per_week: true` as `1` or `"3"` as `3`. PATCH can accept `archived: "false"` as a boolean. The core non-integer test bypasses HTTP parsing, so it cannot catch this. Enforce the declared JSON types before coercion and add POST and PATCH tests asserting `422 validation_error` and unchanged persisted state.
4. **[blocker] `src/habits/storage/repository.py:40` — A valid integer ID can produce a 500.** The path contract has no integer bounds. An ID of `9223372036854775808` parses as a Python integer, but SQLite cannot bind it. Such an ID cannot identify an existing habit. Handle IDs outside SQLite’s signed 64-bit range before binding and test GET, PATCH, and DELETE for `404 habit_not_found` at both ends of the range.
5. **[blocker] `migrations/env.py:36` — Alembic can migrate the wrong database.** The online path always opens an engine from the URL and ignores `config.attributes["connection"]`, which `docs/ai/contracts/storage.pyi` explicitly supports. A caller supplying a connection can therefore upgrade the configured file while its intended database stays untouched. Use the supplied connection when present and leave its lifecycle to the caller. Test with a connection and a URL pointing to two different databases, then verify which one received `habits`.
6. **[blocker] `src/habits/api/errors.py:42` — Framework-generated HTTP errors bypass the promised envelope.** An unsupported method such as `PUT /habits` receives FastAPI’s default `{"detail": ...}` response. Install a handler for Starlette HTTP exceptions that emits `Error` and preserves protocol headers such as `Allow`. Add real-app tests for a 405 and an unmatched-route 404. `test_domain_error_mapping` and `test_validation_error_envelope` exercise different handlers.
7. **[minor] `tests/storage/test_migrations.py:31` — The drift test misses two properties of revision 0001.** Removing the `archived` server default or `ck_habits_frequency` from the migration can leave this test green. `test_frequency_check_constraint` builds its table from ORM metadata. Enable server-default comparison and exercise the frequency constraint on a migrated database.
8. **[minor] `src/habits/api/schemas.py:12` and `src/habits/api/schemas.py:80` — Required response fields are declared optional to supply.** The contract requires `Health.status` and `ErrorBody.details`, including when `details` is null. Both models supply defaults, so omission passes model validation. Make the fields required, pass `status="ok"` explicitly from `/health`, and assert the required fields in the generated M1 response schemas.
9. **[minor] `tests/test_architecture.py:66` — The boundary check skips part of the storage module.** `docs/ai/modules.yaml` assigns `migrations/**` to storage, but the scanner only visits `src/habits/storage`. A migration importing `habits.api` would pass. Scan migration Python files under the storage rules and add a scanner test for that import.
10. **[minor] `pyproject.toml:9` — The declared FastAPI minimum cannot import the app.** `src/habits/api/deps.py:26` uses `Depends(..., scope="function")`, which FastAPI 0.115 does not support. Raise the minimum to 0.121.0, which introduced dependency scopes. The frozen-lock smoke test covers the resolved version only.
11. **[minor] `docs/plan/initial-overview.md:99` — The M1 drift-log row is missing.** Section 10 calls for one entry per milestone. Record the M1 assessment there, including an explicit “none” if the fixes bring the implementation back to the frozen baseline.
